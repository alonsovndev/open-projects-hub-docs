# Work Items & Epics

This directory contains all the epics for the Open Freelancer Project Hub. Each epic is a major component of work that contributes to the Minimum Viable Product (MVP).

Each epic folder contains:

- `epic.md`: A detailed description of the epic, including its goals, scope, and context.
- `stories.md`: A collection of user stories associated with the epic.

## MVP Epics

| Epic ID                                           | Summary                                                                  |
| ------------------------------------------------- | ------------------------------------------------------------------------ |
