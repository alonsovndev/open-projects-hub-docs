# Open Projects Hub documentation

Open Projects Hub helps freelancers turn client notes into reviewed user stories and an approved project backlog. This site presents the requirements, implementation, and engineering decisions behind the master's final project.

**Start with the [reviewer guide](./00-context/reviewer-guide.md).** It introduces the contribution, recommends a reading order, and follows one request from raw notes to client review. The [evidence and limitations](./00-context/evidence-and-limitations.md) page separates implemented behavior from quality targets and evaluation work still needed.

## Run or inspect the system

The system is deployed at [oph.alonsovndev.com](https://oph.alonsovndev.com), with its API at `api-oph.alonsovndev.com`. The [run guide](./00-context/run-the-system.md) covers creating an account, running everything locally, configuration, and verification. Availability of the deployment was not checked while writing this documentation.

See the repository [README](https://github.com/alonsovndev/open-projects-hub-docs) for how to
run this site locally, and [CONTRIBUTING](https://github.com/alonsovndev/open-projects-hub-docs/blob/main/CONTRIBUTING.md)
for how to contribute.
