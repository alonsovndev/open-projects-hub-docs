Project Requirements — Client Portal Refresh

Final Approved User Stories
CPS-104

As a returning user, I want to view my recent activity on the dashboard so that I can quickly resume my ongoing tasks.

Validation Criteria

  • check_circle Dashboard displays a "Recent Activity" component in the primary viewport.
  • check_circle Shows at least 5 most recent actions performed within the last 30 days.
  • check_circle Each activity item includes a direct deep-link to the relevant resource.
CPS-102

As a user, I want to filter my project list by status so that I can focus on active engagements.

Validation Criteria

  • check_circle Filter dropdown contains options for 'Active', 'Archived', and 'Pending'.
