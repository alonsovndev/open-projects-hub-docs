# Epics Index

This directory contains all the epics for the Open Projects Hub. Each epic is organized into its own folder, containing the following files:

- `epic.md`: A detailed description of the epic, including its goals, scope, and context.
- `stories.md`: A collection of user stories associated with the epic.
