# Epic: Inquiry and appointment request baseline

**Epic Title**: Inquiry and appointment request baseline
**Epic Key**: EPIC-02
**Summary**: Deliver a short, privacy-conscious inquiry workflow that captures request intent without direct scheduling.
**Labels**: mvp, inquiry-flow, privacy, conversion
**Priority**: Must Have
**Components**: Frontend, Backend
**Fix Version**: MVP-1

---

**Epic Description:**
Problem Statement: Patients need a low-friction way to request help without being forced into direct booking or oversharing sensitive information.

Objective: Launch a minimal-data request flow with clear validation, submission feedback, and manual follow-up expectations.

Included scope:

- Short inquiry and appointment-request flow without live booking
- Minimal approved field set and privacy-conscious data collection boundaries
- Clear validation, submission success messaging, and manual follow-up expectations

Excluded scope:

- Real-time scheduling calendars or availability selection
- Expanded health-history capture or insurance workflows
- Automated lead scoring, attribution, or analytics dashboards

Related feature and requirement IDs: F-002; FR-002-01, FR-002-02, FR-002-03, NFR-002-01, NFR-002-02, NFR-X01

Dependencies:

- [Project Requirements by Feature](../../01-requirements/readme.md)
- [F-002 Inquiry and Appointment Request Flow](../../01-requirements/f-002-inquiry-and-appointment-request-flow.md)
- [Open Questions](../../open-questions.md)
- [Prototype Brief](../../05-prototype/prototype-brief.md)

Measurable success criteria:

- Visitors can complete the MVP request flow in two minutes or less during validation.
- Inquiry capture remains limited to approved minimal data and excludes unnecessary health information.
- Submission feedback sets clear next-step expectations without promising direct booking.
